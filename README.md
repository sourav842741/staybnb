# Airbnb Clone Project

A fully responsive Airbnb-like web application built for learning and practice purposes. Users can view listings, add new listings, and interact with the platform similar to Airbnb.

## Features

- ✅ View property listings  
- ✅ Add new property listings  
- ✅ Responsive design for mobile and desktop  
- ✅ Interactive UI components
